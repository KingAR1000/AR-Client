Do I need to own Minecraft?

Yes. AR Client uses official Microsoft authentication and checks access to Minecraft Java Edition. It does not include Minecraft or bypass account ownership.

Which Minecraft version should I use?

New installations default to the latest stable official release, currently 26.3. You can select older supported releases down to 1.21.9. Existing installations keep their version so an update cannot silently upgrade your worlds. Mods and loaders must support the version you select.

Is everything ready for everyday use?

AR Client is a development build. Native Windows builds, installation checks, and automated tests are available, but signed updates and authenticated gameplay still need verification. The AR HUD requires Fabric and a matching version-specific build. Read the validation notes for the tested scope and remaining limitations.

Where do I report a problem?

Open a GitHub issue with your game version, loader, and error message. You can also email hello@kingar1000.xyz. Never include access tokens, passwords, or API keys in a report.
